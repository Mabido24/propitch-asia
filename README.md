# ProPitch Asia

Static marketing site for ProPitch Asia — elite football connections in Southeast Asia.

## Local development (Laragon)

1. Place this folder under Laragon `www` (e.g. `D:\laragon\www\propitch-asia`).
2. Open **http://propitch-asia.test** (or **http://localhost/propitch-asia/**).

## Production

Deployed on **Cloudflare Pages** from the `main` branch on GitHub.
